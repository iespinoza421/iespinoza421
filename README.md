### 03. Credit Risk Analytics

**Financial Data Analytics | Python · Tableau · Statistical Analysis**

An exploratory credit risk analytics project using the UCI Statlog German Credit dataset.

The project combines data preparation, statistical inference, automated validation, and interactive Tableau visualization to examine historical credit risk classifications.

| Credit Records | Statistical Associations Tested | Automated Tests |
|---|---|---|
| **1,000** | **6** | **7 Passed** |

**Key Highlights**

- Prepared and validated 1,000 historical credit records, including 700 Good and 300 Bad risk classifications.
- Developed an interactive Tableau dashboard featuring executive KPIs, credit risk segmentation, and loan purpose filtering.
- Calculated 95% Wilson confidence intervals to evaluate uncertainty in segment-level classification rates.
- Applied chi-square independence tests, Cramer's V effect sizes, and Holm correction for multiple comparisons.
- Identified Checking Account Status as the strongest observed association among six evaluated dimensions (Cramer's V = 0.3517).
- Implemented automated data quality tests and documented statistical assumptions and limitations.

**Technologies:** Python, Pandas, SciPy, Statsmodels, Tableau, Pytest, Git

[**View Project & Documentation →**](https://github.com/iespinoza421/credit-risk-analytics)

[**Explore Interactive Tableau Dashboard →**](https://public.tableau.com/app/profile/isaac.espinoza.montero/viz/CreditRiskAnalyticsExecutiveDashboard/CreditRisk-ExecutiveOverview)
